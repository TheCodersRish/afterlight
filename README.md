# AFTERLIGHT

Private source backup for **Afterlight** (UE 5.8 Lyra-based arena shooter with Eclipse Rifts).

## What’s in this repo
- `Source/` — game C++ (including Eclipse Rifts + branding)
- `Config/` — Afterlight/Null-OSS/frontend boot settings
- `Build/` — itch packaging script
- `Plugins/` — plugin modules **without** Content (Content lives in Epic Lyra / local cook)

## Packaged builds
Mac build is attached to GitHub **Releases** and kept locally at:
`~/Games/Afterlight/Mac/`

## Controls
- **Q** / Mouse4 — Solar rift
- **E** / Mouse5 — Void rift
- **R** — Rift Pulse
